## Bot 指令

| 指令 | 用途 |
| --- | --- |
| `/start` | 開始使用。 |
| `/help` | 查看說明。 |
| `/remind 明天下午三點提醒我倒垃圾` | 建立提醒。 |
| `/list` | 列出未到期提醒。 |
| `/cancel R-8F3K` | 取消提醒。 |
| `/timezone Asia/Taipei` | 設定時區。 |
| `/groupmode on\|off\|status` | 查看或切換群組自然語言模式。 |
| `/ai` | 私聊管理個人 Gemini／Groq Key、開關及備援順序；`/ai group` 查看群組授權與設定。 |

## 個人 AI 設定（選用）

- **預設：** 內建規則解析，不分免費／付費使用者。
- **AI：** 自備 Gemini／Groq Key，平台不提供 Key 或代付費用。

### 新增 Key

與 Bot 私聊，輸入：

```text
/ai add gemini <你的 Gemini API Key>
/ai add groq <你的 Groq API Key>
```

- 選一個供應商即可；省略供應商時預設 Gemini。
- Groq 固定使用 `openai/gpt-oss-120b`，不支援切換模型。
- 首次新增 Key 會開啟 AI；曾手動關閉者需輸入 `/ai on`。
- 私聊輸入「明晚八點叫我拿包裹」，核對確認卡後建立。
- 確認卡顯示實際解析來源；缺少可讀模型名稱時顯示「使用 AI 解析」。Groq 無此 metadata，供應商與模型 ID 仍保存於解析紀錄。

### 常用管理指令

| 想做什麼 | 指令 |
| --- | --- |
| 查看狀態與 Key ID | `/ai` |
| 關閉／重新開啟 AI | `/ai off` ／ `/ai on` |
| 新增備援 Key | `/ai add gemini <Key>` ／ `/ai add groq <Key>` |
| 將某組 Key 優先使用 | `/ai move <Key ID> 1` |
| 刪除 Key | `/ai delete <Key ID>` |

### 費用、資料與失敗處理

| 項目 | 行為 |
| --- | --- |
| 費用 | 由供應商帳號／專案計費，付費帳號可能直接扣費，不另跳確認；多組 Key 可能共用額度。 |
| Key 保存 | 經 Telegram 傳至 Bot，加密保存。 |
| 私聊資料 | AI 啟用後，一般文字與必要上下文送至實際供應商；備援時可能依序送至 Google、Groq。 |
| 群組資料 | 需另行授權；觸發訊息與必要上下文只送至指定 Key 的供應商。 |
| 等待 | 共用 18 秒預算；私聊最多試三組 Key，群組只試指定的一組。逾時不代表 Key 失效或額度耗盡。 |
| 私聊失敗 | 保留草稿，可重試；或 `/ai off` 後重送，改用內建解析。 |
| 群組失敗 | 降級為內建解析並提示，仍需確認才建立。 |

解析約束：

- 明確的時間與事項由共用本機規則定案，事項保留原文。
- 只補時間時，保留草稿日期、事項、對象與週期。
- 已確定欄位不再追問；未解條件保留。無效或已過的時間會追問，不由模型改成其他日期。
- 其他口語歧義仍須確認。

錯誤處理：

- 顯示憑證、權限、額度／速率、連線、逾時或服務異常，不顯示上游錯誤原文。
- `/ai` 保存最近失敗原因，重啟後保留；呼叫成功後清除。
- HTTP 429 僅在供應商提供配額資訊時區分每日額度或速率，否則標示無法確認。
- 憑證或權限錯誤會停用 Key；修正後需刪除重加。

## 群組使用

- 建立提醒：`/remind@你的BotUsername 明天下午三點提醒我倒垃圾` 或 `@你的BotUsername 提醒我明天倒垃圾`。
- Bot 追問時，直接回覆下一句。
- 一般群組聊天預設不觸發提醒。

### 群組 AI 授權

群組 AI 預設關閉，**不會使用發訊者或管理員的個人 Key**。要共用 AI：

1. 管理員在目標群組輸入 `/ai group allow`，Bot 會開放一次綁定，並顯示「授權我的 Key」按鈕。

2. Key 持有人點按鈕進入 Bot 私聊，再點選自己已保存的 Key；清單以供應商與指紋區分，點選即同意授權。
   不必查詢或輸入群組 ID、Key ID；若 Telegram 顯示「開始」，先點一下即可顯示 Key 清單。
   沒有既有 Key 時會提示先用 `/ai` 新增，再回群組點按鈕。Bot 會查核群組成員與 Key 所有權。

3. 管理員在群組用 `/ai group` 核對持有人，再輸入 `/ai group on` 同意啟用。
   同一人可以完成持有人及管理員兩種角色。

- **資料與費用：** 觸發訊息與必要上下文送至指定 Key 的供應商，費用歸 Key 持有人；不傳全部群聊。
- **Key 隔離：** 只用授權的一組，不用任何人的其他備援 Key；個人 `/ai on|off` 不影響群組。
- **降級：** 未綁定、關閉、撤銷授權或 Key 不可用時用內建解析；呼叫失敗會提示降級。
- **確認：** 由發起者確認才建立，確認卡顯示草稿的實際解析來源。

| 想做什麼 | 指令與位置 |
| --- | --- |
| 查看自己的群組授權 | 私聊 `/ai group` |
| 隨時撤銷自己的授權 | 私聊 `/ai group revoke <群組 ID>` |
| 暫停／恢復群組 AI | 管理員在群組 `/ai group off` ／ `/ai group on` |
| 解除群組綁定 | 管理員在群組 `/ai group unlink` |
| 改綁另一組 Key | 管理員 allow → 點群組授權按鈕 → 私聊選 Key → 管理員 on；換綁後須重新同意 |

- 刪除 Key 會立即清除所有群組引用。
- 一般成員不能管理群組 AI 或查看 Key ID。
- Bot 需能查核成員與管理員；Telegram 權限查詢失敗時不變更設定。

### 群組自然語言模式

- 管理員輸入 `/groupmode`，用狀態卡的「開啟／關閉」按鈕切換。
- 指令選單可能直接送出 `/groupmode`，之後再用卡片切換。
- 也可直接輸入：

```text
/groupmode status
/groupmode on
/groupmode off
```

開啟後，群組才會接受較明確的提醒句型，例如：

```text
提醒我明天倒垃圾
明天提醒我倒垃圾
週五下午提醒我開會
明天下午三點提醒 @alice 倒垃圾
```

若 BotFather 的 Group Privacy 沒關，bot 仍收不到一般群組訊息。請到 `@BotFather` 執行 `/setprivacy`，選擇 bot 後設為 `Disable`；若原本已在群組，必要時把 bot 移除後重新加入。

## 回報解析問題

1. 在確認卡「使用 … 解析」旁點「回報問題」。

2. 在 Bot 私聊選原因、預覽原句與解析結果，再按「送出回報」。

- **資格：** 僅草稿建立者可回報；須在草稿取消、確認或過期前送出。
- **必要資料：** 每筆回報都包含原句與解析結果，送出前顯示預覽；過長欄位會截短。
- **預期結果（選填）：** 點「補充預期結果」輸入最多 500 字，可預覽、修改或移除；超長不截短。只補充回報，不會修改提醒。
- **暫存：** 未送出的補充只保留至草稿過期；Bot 重啟後需重新填寫。
- **回報者：** 送出前告知會記錄 Telegram user ID 與帳號（如有），供維護者查閱。
- **提醒：** 回報後仍可回原聊天確認或取消。
